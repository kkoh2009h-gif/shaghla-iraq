# خادم شَغلة

خادم مستقل باستخدام FastAPI وSQLite، بدون Supabase أو Firebase.

## تشغيل محلي
1. أنشئ بيئة Python وثبّت: `pip install -r requirements.txt`
2. شغّل: `uvicorn app.main:app --host 0.0.0.0 --port 8000`
3. فحص الصحة: `GET /health`
4. توثيق API: `/docs`

**تنبيه أمني:** هذه نسخة MVP أولية. نقاط إنشاء الوظائف والتقديم تستخدم معرفات مرسلة من العميل ولا تحتوي بعد على مصادقة حقيقية أو تحقق صلاحيات؛ لا تنشرها للعامة قبل إضافة تسجيل آمن، OTP عبر مزود SMS حقيقي، جلسات وصلاحيات خادمية، حدود طلبات، وتهيئة قاعدة بيانات إنتاجية.
