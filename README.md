# شَغلة — SHAGHLA 🇮🇶

**شغلك أقرب إلك.**

منصة عراقية لربط الباحثين عن عمل بأصحاب العمل. البداية من كركوك ثم التوسع إلى بقية المحافظات.

## التقنية
- Android: Kotlin + Jetpack Compose.
- Backend: FastAPI + SQLAlchemy.
- Database: SQLite للتطوير، PostgreSQL للإنتاج.
- CI: GitHub Actions لبناء APK وتشغيل اختبارات API.
- لا نعتمد Replit أو Supabase أو Firebase.

## المنجز في نسخة التطوير 0.3
- واجهة Android عربية RTL مع الرئيسية والوظائف والمحفوظات والحساب.
- API للوظائف مع البحث والفلاتر والتفاصيل والترقيم.
- حسابات عامل وصاحب عمل.
- تسجيل دخول برقم الهاتف العراقي +964 عبر OTP.
- رموز OTP منتهية الصلاحية ومحدودة المحاولات، ولا تظهر في استجابة API.
- جلسات Bearer موقعة بمفتاح خادمي.
- صلاحيات الخادم تمنع العامل من نشر وظيفة وصاحب العمل من التقديم كعامل.
- صاحب العمل يرى وظائفه، والعامل يرى طلباته.
- منع التقديم المكرر.
- اختبارات آلية عبر GitHub Actions.

## تشغيل Backend
راجع [دليل الخادم](backend/README.md) لإعداد قاعدة البيانات ومفتاح المصادقة وربط بوابة SMS وتشغيل FastAPI والاختبارات.

## بناء APK
افتح تبويب Actions في GitHub، اختر آخر تشغيل ناجح من **Build Android APK**، ثم نزّل Artifact باسم `shaghla-android-debug`.

## قبل الإطلاق العام
تسجيل OTP يحتاج مزود رسائل حقيقي يدعم العراق +964 ومفاتيح API في بيئة الاستضافة. يلزم نشر Backend على HTTPS وربط Android بعنوانه، والانتقال إلى PostgreSQL مع نسخ احتياطي وترحيلات، وإكمال لوحة الإدارة والبلاغات وإدارة حالات الوظائف والطلبات، ثم إجراء مراجعة أمنية. لا تدخل بيانات حقيقية في نسخة التطوير الحالية.
