# شَغلة — SHAGHLA 🇮🇶

**شغلك أقرب إلك.**

منصة عراقية لربط الباحثين عن عمل بأصحاب العمل. البداية من كركوك ثم التوسع إلى بقية المحافظات.

## التقنيات
- Android: Kotlin + Jetpack Compose
- Backend: FastAPI
- Database: SQLite للتطوير، مع إمكانية الانتقال إلى PostgreSQL عند النشر
- CI: GitHub Actions لبناء APK وتشغيل الاختبارات

## الحالة الحالية
هذه بداية MVP: واجهة Android أولية وAPI أولي مع قاعدة بيانات. الوظائف الظاهرة في التطبيق بيانات توضيحية فقط، ولا يوجد بعد تسجيل مستخدمين حقيقي أو OTP أو صلاحيات آمنة. لا تستخدم الخدمة للإطلاق العام قبل إكمال المصادقة والتحقق من الأدوار وحماية API وإعداد الاستضافة.

## البناء
يعمل GitHub Actions تلقائياً عند كل تحديث إلى main. افتح تبويب Actions ثم نزّل Artifact باسم `shaghla-android-debug`.
