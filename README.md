# شَغلة — SHAGHLA 🇮🇶

**شغلك أقرب إلك.**

منصة عراقية تربط الباحثين عن عمل بأصحاب العمل. الانطلاقة من كركوك مع قابلية التوسع إلى جميع المحافظات.

## التقنية
- Android: Kotlin + Jetpack Compose، واجهة عربية RTL.
- Backend: FastAPI + SQLAlchemy.
- Database: SQLite للتطوير، PostgreSQL للإنتاج.
- CI: GitHub Actions لبناء APK وتشغيل اختبارات الخادم.
- لا نستخدم Replit أو Supabase أو Firebase.

## الموجود حالياً
- تسجيل دخول برقم هاتف عراقي عبر OTP، مع اختيار نوع الحساب: عامل أو صاحب عمل.
- تخزين جلسة الدخول محلياً على الجهاز.
- عرض الوظائف الحقيقية من API والبحث فيها.
- تقديم العامل على الوظيفة.
- نشر صاحب العمل لوظيفة جديدة.
- صلاحيات الخادم تمنع العمليات غير المسموحة حسب نوع الحساب.
- اختبارات آلية للخادم وبناء APK عبر GitHub Actions.

## تشغيل الخادم
راجع [دليل الخادم](backend/README.md). يحتاج الخادم إلى مفتاح مصادقة قوي، قاعدة بيانات، ومزود SMS حقيقي لإرسال رموز OTP.

## ربط تطبيق Android بالخادم
عند فتح التطبيق لأول مرة:
1. أدخل عنوان API المنشور عبر HTTPS، من دون إضافة مسار `/docs`.
2. أدخل رقم هاتف عراقي واختر نوع الحساب.
3. اطلب رمز التحقق وأدخله بعد وصول SMS.
4. بعد الدخول، يمكنك استعراض الوظائف والتقديم عليها، أو نشر وظيفة إذا كان الحساب لصاحب عمل.

عنوان الخادم لا يُضمّن داخل APK؛ يمكن إدخاله من شاشة تسجيل الدخول. لا تستخدم عنواناً تجريبياً أو بيانات حقيقية قبل نشر الخادم وتأمينه.

## تنزيل APK
من [تشغيل بناء Android](https://github.com/kkoh2009h-gif/shaghla-iraq/actions)، افتح آخر تشغيل ناجح لـ **Build Android APK** ثم نزّل artifact باسم `shaghla-android-debug`.

## ما يمنع الإطلاق العام حالياً
- لا يوجد حتى الآن عنوان Backend إنتاجي منشور عبر HTTPS.
- يلزم إعداد مزود SMS يدعم العراق +964 ووضع بياناته السرية في بيئة الاستضافة.
- يلزم إعداد PostgreSQL إنتاجي ونسخ احتياطي وترحيلات قاعدة البيانات.
- يلزم إكمال إدارة طلبات المتقدمين من واجهة التطبيق، الملف الشخصي، البلاغات ولوحة الإدارة، ثم إجراء مراجعة أمنية وسياسة خصوصية وشروط استخدام.

**مهم:** نجاح بناء APK واختبارات API لا يعني أن خدمة الرسائل أو الخادم منشوران. لا تدخل بيانات شخصية حقيقية في النسخة الحالية قبل إتمام الإعدادات أعلاه.
